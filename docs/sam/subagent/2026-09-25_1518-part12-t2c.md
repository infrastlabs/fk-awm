### 每一级的盲区

- **T2 的假通过**：rc.lua 报错时 awesome `exit(1)`，但进程 8s 挂满被 SIGKILL
  也是 rc=137——两者退出码撞车，T2 无法区分。
- **T2b 的补位**：grep `traceback|attempt to call|bad argument|interval must
  be|E: awesome`，抓出 pango UAF 刷屏（89 MB 冒烟日志那种）。
- **T2b 的盲区**：rc.lua 加载干净、进程没崩，不代表"某个具体 draw 分支真的
  执行过"。systray 在 Xvfb 下从未执行（无 tray client → `systray.lua:118`
  fit 0×0 → `hierarchy.lua:338` 空 clip 跳过），T2/T2b 依然全绿。
- **T2c 的补位**：用**执行计数**替代"没报错"。

### T2c 判据（不是 rc，是计数）

```
draw_entered >= 1    draw() 被真的调用
utd_calls   >= 1     cr:user_to_device_distance 跑过（systray.lua:75 之后，全 lib/ 唯一调用点）
draw_errors == 0     跑完没抛错
utd_bad     == 0     返回了两个真数字
```

`utd_calls>=1` 是 load-bearing：`cr:user_to_device_distance` 只在
`systray.lua:75` 一处被调（grep 验证），且在 draw() 所有 guard 之后。
